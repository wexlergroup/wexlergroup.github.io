# Data and Reproducibility

The Wexler Group shares computational inputs, curated structures, and course materials that support our publications and
teaching. The resources below include example files and instructions for requesting project data.
{: .text-justify}

## How to Access Datasets

- Project-specific data are distributed with manuscripts or software releases when possible. If a link is unavailable,
  contact us to ask whether the files can be provided.
- Course syllabi are available from the [Teaching](/teaching/) page.
- Email [wexler@wustl.edu](mailto:wexler@wustl.edu) with the project name or publication to request additional inputs,
  trajectories, or processed data.

## Data Use

- Cite the associated publication when reusing files or derived data.
- Report problems by email. We maintain versioned inputs and update links when new datasets are released.
