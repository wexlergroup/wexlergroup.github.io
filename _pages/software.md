## Group-Developed Software

<article class="software-project" aria-labelledby="freebird">
  <header class="software-project-header">
    <h3 id="freebird">FreeBird.jl</h3>
    <img src="../assets/freebird/logo.png" alt="FreeBird.jl logo" class="software-logo" loading="lazy">
  </header>
  <p class="software-description">FreeBird.jl is a Julia package for statistical thermodynamic modeling of defects in materials. It supports lattice and atomistic models and implements direct quadrature, Metropolis Monte Carlo, replica exchange, Wang–Landau sampling, and nested sampling.</p>

## Contributions to Other Software Projects

<article class="software-project" aria-labelledby="pymatnest">
  <header class="software-project-header">
    <h3 id="pymatnest">pymatnest</h3>
  </header>
  <p class="software-description">pymatnest is a library for nested-sampling calculations on clusters and bulk materials. It calculates thermodynamic variables across temperatures, locates phase transitions, and determines phase diagrams. Calculations can use LAMMPS or the supplied Fortran models and either Monte Carlo or molecular dynamics sampling.</p>
  <div class="software-links">
    <a href="https://libatoms.github.io/pymatnest/" aria-label="pymatnest documentation">Documentation</a>
    <a href="https://github.com/libAtoms/pymatnest" aria-label="pymatnest GitHub repository">GitHub Repository</a>
  </div>
</article>
